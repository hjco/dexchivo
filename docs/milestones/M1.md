# M1 · Autenticación, base de datos y mercado público

## Estado

Completado (pendiente aprobación para M2).

## Entregables

- Monorepo con paquetes `@chivo/contracts`, `@chivo/security`, `@chivo/database` y apps `api`,
  `dashboard`, `services/python-engine`.
- PostgreSQL schema con `users`, `sessions`, `audit_logs`, `instruments`, `candles`.
- Migración inicial y `db:seed` con administrador único (`ADMIN_PASSWORD` requerido).
- Autenticación httpOnly `chivo_session`, login con throttle, cierre de sesión, auditoría, 2FA TOTP
  opcional con `AUTH_ENCRYPTION_KEY`.
- Mercado público Binance USD-M (fapi) con normalización decimal, persistencia, `source`
  `BINANCE|CACHE`, fallback con caché local.
- SSE autenticado `/api/v1/market/stream` con eventos `status` y `candle`.
- Dashboard en español: login, panel con gráfico `lightweight-charts`, enlace Seguridad, cierre de
  sesión. Solo PAPER.
- Readiness `/health/ready` comprueba configuración, PostgreSQL y Redis (503 si falla).
- Sin credenciales de exchange, sin órdenes, sin LIVE.

## Comprobar localmente

```bash
pnpm install
docker compose up -d --wait
cp .env.example .env  # configurar AUTH_ENCRYPTION_KEY opcional y ADMIN_PASSWORD
pnpm db:migrate
pnpm db:seed
pnpm dev:api
pnpm dev:dashboard
```

## Notas de seguridad

- Las contraseñas se hashean con scrypt.
- Los secretos TOTP se cifran con AES-256-GCM cuando `AUTH_ENCRYPTION_KEY` está presente.
- Las sesiones son opacas (sha256 del token) almacenadas en BD.
- Las claves nunca se registran ni se envían al navegador.
- El bloqueo de logins es por proceso (recomendado ejecutar una instancia de API en M1).
